PIXEL SQUADRON
==============
A tiny top-down twin-stick arena shooter. No installer, no admin rights.

HOW TO RUN
  Windows : double-click  pixel_squadron.exe
  Linux   : chmod +x pixel_squadron  &&  ./pixel_squadron
  macOS   : right-click the binary -> Open  (unsigned build)
            or:  ./pixel_squadron

Keep this folder together - the game loads its art and sound from ./assets.
Settings are saved next to the program as settings.cfg.

Windows may show a SmartScreen prompt because the build is unsigned:
   More info  ->  Run anyway

CONTROLS
  WASD / left stick ....... move
  Mouse / right stick ..... aim
  LMB / RT ................ fire
  Shift / B ............... boost
  Q / X ................... recall the squadron
  E / Y ................... blast (ultimate)
  G / ESC ................. pause + graphics settings
  F11 ..................... fullscreen
  M ....................... mute
  C ....................... gamepad bindings
